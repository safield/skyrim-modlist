19. NAT.ENB III — weather plugin ONLY — install NAT.ENB - ESP WEATHER PLUGIN v3.1.1C - Fixed. Do not install ENB binaries or any actual ENB preset. NAT.CS III explicitly requires this weather ESP as its base. Nexus Mods
20. Community Shaders — official release. Current official version is 1.9.1. This replaces ENB as our rendering framework. Nexus Mods
21. Skylighting — Community Shaders — install the current CS Skylighting plugin. NAT.CS III specifically requires Skylighting. Cloud Shadows does not need a separate install anymore because it has been incorporated into current Community Shaders. Nexus Mods
22. NAT.CS III — install after NAT's weather ESP and Community Shaders; allow NAT.CS III to overwrite the NAT III weather plugin where applicable. This provides the actual NAT visual/weather treatment tuned specifically for Community Shaders. Nexus Mods
23. Light Placer — current version appropriate for your Skyrim runtime. The current 5.0 release explicitly supports 1.6.1170 and 1.7.104+. Nexus Mods
24. ISL Helper SKSE — latest version compatible with your runtime. This dynamically converts lights to Community Shaders' inverse-square lighting system and is a requirement for the current Lux CS setup. Nexus Mods
25. Lux Orbis — existing choice.
26. Lux — existing choice.
27. Lux CS — install after Lux and Lux Orbis. Use its Light Placer / ISL configuration. For our setup select the Non-Effects11 option because NAT.CS III explicitly says it is not compatible with Community Shaders Effects 11. Lux CS 2.6 provides separate Effects11 and Non-Effects11 configurations. Nexus Mods
Then, only after everything above is finalized:
28. ParallaxGen / PG Patcher — run against the completed mesh/texture setup.
29. xLODGen
30. TexGen
31. DynDOLOD 3 — run last.
